# refs-texts/ —— 参考文献原书资料库

**用途**：任务清单第 13 条「参考文献原书放项目里可查原文」。

**边界（版权红线，不可含糊）**：
- 只收**公版古籍**原文 —— 明清及以前传本、作者不详的民俗文本。
- 现代著作、开源库、网站整理件**一律不入**（有著作权，只列书目，请阅原书）。
  判定标准见 `modules/RefsModule/refs.js` 文件头「版权边界」一节。
- 本目录**不打包进小程序**（未登记进 `tools/platform-modules.json`），
  仅供仓库内查阅；App 内可查原文走 `refs.js` 的 `QUOTERS`（单一真源在各内核文件里）。

**与 App 内「参考文献」页的关系**：
- App 内页面 = `refs.js` 的 `refsPage()`（23 种书目 + 432 条内核汇整原文）。
- 本目录 = 同一批公版书的**原书全文**，供逐字核对、引用溯源。
